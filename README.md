# Manga Tracker – vídeos promocionales

- `grabaciones/` → sube aquí las grabaciones de pantalla de la app (máx. 25 MB, mejor en 720p).
- `procesadas/` → la tarea automática mueve aquí las grabaciones ya convertidas en vídeos.
- Los vídeos terminados se publican como *Releases* de este repositorio y se programan en Metricool (TikTok, Instagram, YouTube).
